# Working on Constrivia

The main project directory is the canonical checkout. Its `main` branch and GitHub's `main` must contain the same latest application after publication.

Work in the main checkout by default. A temporary worktree is only for a short-lived experiment or integration: bring completed changes back into the main checkout before publishing and remove the temporary checkout afterward. Do not keep publishing from a separate worktree while the main directory stays behind.

Before publishing, incorporate all completed local changes, run the appropriate regressions, and check the staged changes. Publish from the main checkout with a normal fast-forward push; never overwrite remote history. Afterward, compare `git rev-parse HEAD` with `git rev-parse origin/main` and confirm that `git status --short` is clean.

Source, public examples, reusable construction materials, tests, and maintained documentation belong in Git. Generated files under `output/`, dated audit reports, local status reports, dependency/build directories, logs, and duplicate ZIP archives are ignored. Ignored files remain available locally.

Handwriting automatically groups nearby strokes during one writing session using ordinary object groups. Screen-sized gaps and vertical alignment keep separate words and writing lines apart while allowing small marks such as dots. A pause of more than six seconds before starting the next stroke ends the sequence; drawing a long stroke does not count as a pause. Changing tools, erasing, loading a page, Undo/Redo and explicit ungrouping end automatic grouping. Groups persist through native save/load and support the existing selection, style, transform and ungroup controls.

The older pre-consolidation local state is retained in Git history through the safety branch `codex/backup-local-20261016-grid`; it is a recovery snapshot, not a development checkout.

See [TESTING.md](TESTING.md) for construction regression checks.

Multipage CTR files contain one JSON document with ordered `pages` and a zero-based `activePage`. Every page is a normal construction document; the active page is also present at the top level for single-page reader compatibility. A single-page export omits both fields. Legacy CTR archives containing multiple JSON files remain supported and open as editable pages. Page edits and their independent Undo/Redo histories are retained while browsing in the current session; saved files contain page content, not edit history. Turning off the multipage toggle requires confirmation and discards all pages and their history.

Points constrained to a finite segment or circle can be assigned a nonnegative speed in drawing units per second and a direction in the point style menu. The animation player contains Play/Pause, a separate Stop, Step and Loop, in that order. Open and Save follow the normal toolbar rule in both modes: visible whenever nothing on the canvas is selected, regardless of the active tool. Play shows Pause while playing and returns to Play while paused. At an endpoint Play and Step are disabled until the separate Stop restores the starting pose. Stop also clears every point trace and remains available before playback to clear manually generated traces. Step pauses playback and advances 0.1 seconds using six substeps of 1/60 second, retaining smooth traces. Reaching an endpoint ends playback; Loop instead reverses all directions at that instant. Motion inputs are evaluated before dependent moving paths, and a segment's positive endpoint order stays fixed during the run. Cyclic motion dependencies cannot be played; conflicting endpoint directions or an excessive number of reversals end the preview instead of spinning or silently dropping time.

Animation speeds use the construction's measurement calibration (`measurementScale`, geometry coordinates per user length unit), for both segments and circular arc lengths; zoom does not affect speed. Without calibration, speed 1 traverses the visible canvas width in three seconds. This fallback scale accounts for zoom and is captured at the start of a run, remaining stable through pauses, zoom changes and resizing. The clock retains elapsed time across delayed frames and pauses when the page becomes hidden. Each callback has a bounded amount of catch-up work without discarding the remaining elapsed time.

An ordinary point constrained only to a circle retains its angle around the center when the circle's inputs move. The geometry solver captures this angle before the move and keeps it through all dependency passes, including compass and computed centers. Directly dragging or animating the perimeter point can change its angle; intersections and other derived points retain their own constraints. This attachment is derived from the current geometry rather than additional persisted state. Missing ray settings represent hidden rays, so saved segments remain eligible animation paths.

Animation controls dock after the contextual actions (Style, Hide, Copy Style and Trash) in the main toolbar when all visible top-level controls fit at their preferred widths. When space is insufficient, only Play/Pause, Stop, Step and Loop move into a separate toolbar below the main bar, with a drag handle supporting mouse, touch and arrow keys. Open and Save occupy fixed positions at the left edge of the main toolbar, in both modes; enabling animation or docking the player never reparents or shifts them. Selecting an object hides these actions; clearing the selection restores their original positions. Choosing a drawing tool alone does not hide them. Undo, Redo and the options menu remain in the main bar. The layout is recalculated after selection and viewport changes. The floating position is a local preference, clamped below the main bar and within the viewport, restored across reloads and retained while docked. Loop is hidden only when the floating toolbar itself cannot fit within the available viewport width.

Stop restores the geometry from the start of the run and clears all point traces. Canvas interaction pauses playback; a construction edit then commits the visible pose as a normal history entry and ends the preview. Editing speed or direction in a paused preview also commits that pose as the new starting point. Undo/Redo first ends the preview, and navigating to another page restores the starting pose before saving that page's session. History jumps break trace paths instead of drawing a spurious connecting line.

CTR files retain motion speeds, directions, loop and enabled state in optional per-page `animation` metadata. Older metadata without `enabled` defaults to enabled. Loading enables the controls unless the page was explicitly saved with animation off; playback never starts automatically. A multipage file may mix plain and animated pages; the player and toggle always follow the current page. The top-level animation metadata only mirrors the active page for compatibility. An enabled trace is saved on its point as `traceEnabled`; recorded trace samples, the playback clock and the Stop snapshot are session-only.

The library's `krzywe-w-ruchu.ctr` is generated by `node scripts/generate-animated-curves.mjs`. Its editable explanatory labels use the optional `viewportAnchor: 'top-left'` to stay visible on different screens; dragging a label releases the anchor. Check the constructions and their layouts with `node scripts/regression/verify-animated-curves.cjs`.

The local file list has one toggle on the right of the folder toolbar, showing Name or Time for the current sort order. Its preference is remembered; Time uses `File.lastModified`, newest first, with missing dates last and name as the tie break. Cloud and library files always sort by name. Cloud storage has no historical modification dates for older files, so the cloud list has no time-sort control and ignores legacy sort preferences. Cloud writes still retain modification metadata alongside the file. New construction filenames default to `YYYY-MM-DD HH-mm-ss`, without a prefix; saving an opened construction retains its existing name.
