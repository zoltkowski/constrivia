# Trójkąt równoboczny za pomocą cyrkla

Otwórz `trojkat-rownoboczny.ctr` w aplikacji przez panel plików → Lokalne. Obok jest czytelna wersja JSON i podgląd na małym ekranie.

1. Wybierz Cyrkiel, wskaż A i B, potem A jako środek pierwszego okręgu.
2. Powtórz dla długości AB i środka B.
3. Narzędziem Przecięcie wskaż oba okręgi. Jeden z punktów przecięcia oznacz jako C.
4. Połącz A, B i C odcinkami.

AC i BC są promieniami równymi AB, więc trójkąt jest równoboczny. Przeciągnięcie A lub B zmienia konstrukcję i zachowuje tę własność. Pomocnicze okręgi są szare i przerywane, a boki i etykiety wyróżnione. Drugi punkt przecięcia daje trójkąt po przeciwnej stronie podstawy.
